## Найденные проблемы и исправления

1. Новый глобальный toast и spinner сделали общий e2e-локатор getByRole('status') неоднозначным. Первый запуск действительно упал на этом месте. Теперь проверяется статус конкретного региона «Уведомления». Успешная выдача не объявляется повторно в постоянном тексте; ошибки действий объявляются role=alert. Регрессионный тест проверяет отказ 409, понятное сообщение и повторную доступность действия. Коммит 61ead29.
2. Существующий guard запрещал параллельные изменения избранного, но кнопки оставались активными, и повторное нажатие игнорировалось без объяснения. Теперь состояние ожидания передается в BookList/BookCard и кнопки отключаются до окончания запроса. Реальная браузерная проверка подтвердила ровно один запрос. Коммит 82c9bc2.
3. Сквозной тест раньше перезаписывал исторический скриншот docs/lab10/fullstack-success.png. Снимок текущего теста перенесен в игнорируемую .tools/stage3/fullstack-success.png. Это диагностический снимок, не финальная иллюстрация DOCX.
