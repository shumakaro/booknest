## Исправленные проблемы

После этапов 11–13 test-образ не содержал новые инструменты, актуальный OpenAPI и generated.ts, которые уже импортируют тесты. Исправлены COPY и `.dockerignore`: нужные файлы включены только в test stage. Runtime API не получает tests/docs; служебные каталоги, секреты, архив docs.zip и остальные документы исключены из контекста. Compose явно выключает учебные коды в логах.

Сквозной сценарий использовал старую подпись «Вернуть книгу №…», замененную на этапе 7. Locator согласован с нынешней кнопкой по названию; сценарий проверяет реальные CRUD/выдачу/возврат, без подмены API фикстурами.

HTTP-smoke расширен с одного SPA-пути до восьми: детали, поиск, желаемое, выдачи, рабочее место, вход, регистрация и редактирование. Проверяются реальные JS/CSS и Content-Type, no-store HTML, immutable статики для Nginx, API/asset 404 без подмены на SPA; запросы ограничены таймаутом. Nginx получил раздельное кэширование index.html/assets с сохранением защитных заголовков в location, где add_header отменяет наследование.

`prepare_container_check.py` создает случайную конфигурацию отдельного стенда без вывода значений. Режим x отказывает при существующем файле; рабочий .env не заменяется. Локальная инструкция — CONTAINER_CHECK.md: отдельный project, loopback-порт/сеть и остановка без -v. CI использует новый файл только внутри disposable checkout.

CI дополнен явным API --check, Ruff для поддерживаемых tools, двумя frontend workers, concurrency одного PR, отдельным Compose project по run_id, JUnit-артефактами и проверкой API runtime non-root/отсутствия tests/docs. Проекты других PR не отменяются и пользовательские тома не удаляются.
