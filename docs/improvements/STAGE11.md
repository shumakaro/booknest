## Подтвержденные расхождения и исправления

1. BookUpdate и AuthorUpdate описывали null как допустимое значение всех необязательных полей, хотя валидаторы уже отклоняли null для обязательных данных. Добавлено уточнение JSON Schema: поле можно пропустить, но null допускается только для ISBN книги и года рождения автора. Внутренний default=None больше не показывается как допустимое значение остальных полей. Условия длины/диапазона сохранены. Python-валидация и правила PATCH не изменены; пустой PATCH остается совместимым.
2. LoanReturn.state в OpenAPI имел const="returned", но генератор игнорировал const и выдавал string. Теперь генерируется точный строковый литерал, включая вложенные union. Это статический тип; HTTP-запросы по-прежнему проверяет сервер.
3. ErrorRead.details имел неопределенный object, хотя реальный обработчик возвращает null либо список loc/msg/type. Введен ValidationIssueRead и точный список в схеме/TS. Input/ctx, пароли и тела запросов в details не добавлялись. В общие документированные ошибки добавлены 400/405; существующий конверт и обработчики сохранены.
4. Генератор по умолчанию читал исторический docs/lab7/openapi.json. Создан актуальный docs/api/openapi.json, генератор использует его. Старые снимки не перезаписаны. Добавлены render_types, --output и --check: проверка ничего не пишет и возвращает 1 при расхождении.
5. Logout фактически допускает отсутствие access (отзыв cookie/повторный выход), но OpenAPI показывал Bearer без альтернативы. Добавлена пустая security-альтернатива; /auth/me по-прежнему требует Bearer. Правила входа/выхода не изменены.

## Защита актуальности

Новые pytest-проверки сравнивают живой OpenAPI приложения с актуальным снимком и сгенерированным TypeScript. Одновременное устаревание снимка и TS не скрывает расхождение с кодом приложения. Проверяется единая схема ErrorRead в документированных ошибках и отсутствие content у 204.

В docs/api/README.md описан порядок обновления без обращения к БД. ROUTES.md содержит таблицу операций, успешных кодов/моделей и security, полученную из текущего снимка. Наличие Bearer в Swagger не заменяет ролевые зависимости, владение и проверки cookie/Origin.

Frontend: **95 passed в 18 файлах**, `--maxWorkers=2`, **72,67 с**. TypeScript/Vite build прошел после регенерации с более точными типами. Работа не означает исчерпывающего аудита всех возможных значений параметров. Генератор покрывает используемые модели, но не является полноценным OpenAPI SDK или runtime-валидатором JS.
