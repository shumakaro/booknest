# Этап 3: поиск, фильтры и навигация — 11 ноября 2026

Ветка codex/catalog-search-filters от завершенного этапа 2 (21ce00c). Область: контракты постоянного API ЛР7, SQL/ORM ЛР8, интегрированные React-страницы и поведенческие тесты ЛР10. Исходные статические работы, отчеты и ветки ЛР1–6 не изменяются.

## Найденные недостатки

Постоянный каталог искал q только в названии, а кнопка возврата из детали всегда открывала /books без фильтров. Прямые ссылки могли передавать API дробную/бесконечную страницу и неизвестные сортировку/жанр. При вводе с задержкой старый запрос мог отправляться с уже сброшенной страницей. Диапазон результатов и отдельное удаление фильтров отсутствовали.

## Что изменено

- CatalogRepository ищет обычный q в названии ИЛИ имени автора. EXISTS не размножает книги; условия применяются до total и LIMIT/OFFSET. Нормализуются пробелы, спецсимволы %/_ ищутся буквально. Прежний дополнительный fulltext по названию сохранен. Схемы ответов, эндпоинты и миграции не менялись.
- Реальный SQL-тест выявил зависимость регистра кириллицы от C-locale локальной PostgreSQL. Для русских заглавных букв, включая Ё, добавлено явное приведение через translate; ASCII-регистр обрабатывается прежним icontains. Вся строка запроса передается параметром. Настройки БД не меняются. Проверка других алфавитов зависит от локали и не объявлена универсальной Unicode-нормализацией; ё и е не считаются одной буквой.
- Новая catalogFilters.ts проверяет URL до API: целая страница 1…1000000, поддерживаемые сортировка/жанр и available=1. Некорректная ссылка исправляется replace-навигацией. Если существующая страница исчезла, после ответа сервера открывается последняя доступная.
- Метки активных условий позволяют удалить только поиск, жанр, доступность или сортировку. Остальные условия сохраняются, страница сбрасывается на первую. Общий сброс сохранен. Подпись поиска объясняет охват всей БД; показаны страница и диапазон фактически загруженных записей относительно серверного total.
- Ввод немедленно отменяет прежний запрос; устаревший ответ игнорируется. Кнопка «Найти» снимает задержку ввода. Набор букв не создает отдельную запись истории для каждой буквы.
- Переход в локальные детали передает исходную внутреннюю ссылку и прокрутку. Возврат сохраняет фильтры, сортировку и страницу, а позиция восстанавливается после загрузки списка. Прямое открытие детали использует /books; внешняя ссылка из состояния навигации не принимается. После удаления возврат также сохраняет условия. Пустой каталог предлагает перейти в отдельный глобальный поиск.
