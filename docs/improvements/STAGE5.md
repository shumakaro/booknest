## Проблемы и исправления

Прежняя форма требовала ISBN, хотя API разрешает null; поэтому книга из Open Library без ISBN не редактировалась. При PATCH отправлялись все поля, включая неизмененные, и выполнялся поиск/создание автора даже при правке названия. Начальные 2020 год и одна страница могли выглядеть подтвержденными данными. Каждый конфликт 409 ошибочно связывался с ISBN, а ошибка 422 без известных полей могла оставаться без сообщения.

Теперь ISBN необязателен: пустое значение становится null. normalizeIsbn проверяет контрольные цифры ISBN-10/13, разрешает пробелы/дефисы и X в последней позиции ISBN-10, корректный ISBN-10 преобразуется в ISBN-13 до любых HTTP-запросов. Название/автор ограничены 200/120 символами, язык — 30, в соответствии с постоянным API. Сохранены межполевая проверка годов и остальные ограничения.

Форма сгруппирована по книге/автору и конкретному изданию, добавлены подсказки и количество экземпляров. При создании годы, язык и страницы остаются пустыми, число экземпляров явно показано как 1 и может быть изменено. Неизвестные годы/страницы не подставляются при загрузке неполных деталей. Имеющиеся серверные значения сохраняются как исходные, их достоверность не утверждается.

При редактировании передается список dirtyFields, из него собирается PATCH. Изменение только названия отправляет только title; жанр, описание, обложка, автор, ISBN и прочие неизмененные сведения сохраняются. Автор ищется/создается только при создании книги или изменении поля автора. Неизмененная форма не отправляется. Это не оптимистическая блокировка: параллельное изменение одного и того же поля по-прежнему требует отдельного механизма версий.

На время сохранения отключены поля, сохранение и отмена; ref защищает от повторной отправки. После отказа данные остаются, фокус переходит к известному полю ошибки или общему сообщению. Неизвестный 422 и общий 409 показываются явно. Успех сбрасывает dirty и вызывает переход только после ответа. Маршруты после создания/редактирования сохранены: создание возвращает в каталог, редактирование — в детали; состояние возврата из деталей передается через редактор.

Сервер отличает известное ограничение books_isbn_key от остальных ошибок целостности и возвращает понятный 409 об ISBN без SQL/внутренних подробностей. Схема ошибки, маршруты и миграции не менялись. Остальные конфликты не объявляются дубликатом ISBN.

Отмена измененной формы требует подтверждения. Существующий обработчик предупреждения при ссылках/закрытии страницы сохранен; браузерный сценарий проверил кнопку отмены и переход по навигационной ссылке. Перехват аппаратной кнопки «Назад» отдельным router blocker не добавлялся и не объявляется проверенным. Удаление подтверждается нативным диалогом с названием книги и объяснением сохранения истории; отказ от диалога не отправляет DELETE, серверный запрет при активной выдаче сохраняется.
