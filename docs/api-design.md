# Проектирование API BookNest

## Ресурсы и права
Префикс каталога `/api/v1`. В ЛР №7 проверяются контракты без авторизации. Начиная с ЛР №9 каталог читается всеми, изменяется библиотекарем; выдачи доступны владельцу или библиотекарю.

| Метод | Путь | Назначение | Успех | Ошибки | Роль после ЛР №9 |
|---|---|---|---|---|---|
| GET | /books | Список книг | 200 | 422 | Любая |
| POST | /books | Создать книгу | 201 | 401,403,404,409,422,429 | librarian |
| GET | /books/{id} | Детали | 200 | 404 | Любая |
| PATCH | /books/{id} | Изменить переданные поля | 200 | 401,403,404,409,422,429 | librarian |
| DELETE | /books/{id} | Удалить | 204 | 401,403,404,409,429 | librarian |
| GET/POST | /authors | Список / создание | 200/201 | 409,422 | Любая / librarian |
| GET/PATCH/DELETE | /authors/{id} | Чтение / изменение / удаление | 200/200/204 | 404,409,422 | Любая / librarian |
| GET | /authors/{id}/books | Книги автора | 200 | 404,422 | Любая |
| GET | /health | Проверка процесса | 200 | 500 | Любая |

Страницы начинаются с 1; size от 1 до 100. Ответ `{items,total,page,size}`. Фильтры книг: q (подстрока названия или имени автора без учёта регистра), genre, available_only. Пробелы по краям и повторные пробелы запроса нормализуются; `%` и `_` ищутся буквально. Условие по автору использует EXISTS и не создает дублей книг. Фильтры применяются до подсчета total и пагинации. sort: поля title, year, id через запятую, минус перед полем означает убывание. id служит дополнительным стабильным ключом. Отдельный дополнительный режим search_mode=fulltext сохраняет прежний полнотекстовый поиск по названию.

## Три ключевые операции
Создание автора: `POST /api/v1/authors`, тело `{"name":"Айзек Азимов","birth_year":1920}`; ответ 201: `{"id":1,"name":"Айзек Азимов","birth_year":1920}`.

Создание книги: `POST /api/v1/books`, тело `{"title":"Учебная книга","author_id":1,"year":2020,"isbn":"9780306406157"}`; ответ 201 содержит эти поля, id, genre, total_copies, description, available, author. Служебные поля не принимаются во входном теле.

Частичное изменение: `PATCH /api/v1/books/1`, тело `{"year":2021}`; ответ 200 сохраняет все остальные поля. `exclude_unset=True` отличает отсутствие поля от явного null. ISBN можно очистить значением null.

## Ошибка
`{"code":"HTTP_404","message":"Запись не найдена","details":null,"request_id":"UUID"}`.
При 422 details содержит loc, msg, type. Исходное значение не возвращается, чтобы не раскрыть пароль при последующем добавлении авторизации. request_id совпадает с заголовком X-Request-ID и записью журнала.

## Самопроверка спецификации
Глаголы из URL исключены, имена ресурсов согласованы, коды ошибок перечислены. Взаимная проверка с однокурсником пока не проведена; самопроверка её не заменяет.
