# Сверка 118 требований ЛР7–12

Источник: [поэлементный индекс](REQUIREMENTS.md), разделы lab7–lab12 из исходной методички. СРС, практики и ответы лекций исключены по последнему решению владелицы. Это сверка кода и доказательств, не выставление оценки и не 118 автоматически закрытых пунктов.

Статусы различают реализацию, исторический протокол, реальный запуск, ручную приемку и подготовленную конфигурацию. Новое изменение в ветке не объявляется опубликованным. Условия текущих запусков — [SELF_WORK](SELF_WORK.md).
