# Самостоятельная проверка перед независимым ревью

Это собственный разбор BookNest. Он не является восемью опубликованными комментариями к проекту однокурсника. Согласованный проект и ответное ревью отсутствуют.

| Место | Последствие | Предложение | Приоритет и статус |
|---|---|---|---|
| deployment nginx HTTPS | Без действительного сертификата пароли нельзя проверять публично | Предоставить домен, выдать сертификат и проверить HTTPS | Блокирующий, безопасность, открыт |
| production environment | Повторное использование ключа разработки связывает две среды | Сгенерировать отдельный ключ на VPS, проверить права файла | Высокий, безопасность, инструкция готова, VPS открыт |
| forwarded headers | Доверие любому источнику позволяет менять ключ ограничения входа | Доверять фиксированному web IP и перезаписывать заголовки | Высокий, исправлено, проверено CI 42236984907 |
| deployment restore.sh | Повторное восстановление создает конфликт данных | Разрешать только отсутствующую тестовую БД | Высокий, реализован отказ, проверено CI 42236984907 |
| App.css badge | Контраст 4,23 недостаточен для мелкого текста | Заменить цвет и повторить Lighthouse | Средний, исправлено, Accessibility 100 |
| client.ts refresh | Ошибка формы после refresh могла завершать сеанс | Разделить обновление токена и повторный запрос | Высокий, исправлено, regression test зеленый |
| e2e paging | Изменение URL раньше ответа API делает проверку нестабильной | Дождаться ответа нужной страницы | Средний, исправлено, CI ЛР11 зеленый |
| docs reports | Непроверенная верстка может содержать переносы и обрезку | Отрендерить все DOCX и просмотреть каждую страницу | Средний, закрыт, просмотрены 52 страницы |

План: завершить CI новых скриптов; выполнить визуальную проверку; после выдачи ресурсов пройти публичный runbook; обменяться независимым ревью и ответить конкретными коммитами. Измеренный дефект N+1 уже подтвержден сокращением 26 запросов до 3; повторное заявление о новом измерении не делается.
