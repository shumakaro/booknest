## Практика 12
Реально проверены подделка роли в JWT (401), истёкший JWT (401), refresh вместо access (401), IDOR существующего чужого пользователя (404), CORS и инъекционная строка поиска. Стенд преподавателя vuln-lab не предоставлен, поэтому воспроизведение его исходных уязвимостей и их исправление не заявляется. Ревью чужого проекта не проводилось: проекта и согласованного участника нет.

## Ограничения
Демо-cookie без Secure допустима только на локальном HTTP. Для эксплуатации требуется COOKIE_SECURE=true и проверенный HTTPS. Ограничители в памяти рассчитаны на один процесс; для нескольких экземпляров нужен общий счётчик. Секреты реального сервера не создаются в Git.
