[28] Практика 9 · W9
[29] Проектирование ресурсного API и первые эндпоинты FastAPI
[30] Цель
[31] Научиться проектировать API до написания кода и проверять его в Swagger UI без готового клиента.
[32] Исходные знания
[33] Python, аннотации типов, коды HTTP, REST-соглашения, лекция 9.
[34] ПО
[35] Python 3.12, venv, fastapi, uvicorn, pydantic, Thunder Client, VS Code с расширением Python.
[36] Пошаговое задание
[37] 1. Проектирование на бумаге (12 минут). Для предметной области своего итогового проекта выписать: сущности; для каждой — таблицу «метод / путь / назначение / коды ответов»; отдельно нестандартные действия как переходы состояния подчинённого ресурса.
[38] 2. Взаимная проверка в парах: сосед ищет в вашей спецификации глаголы в URL, отсутствующие коды ошибок и несогласованные имена. Исправить найденное.
[39] 3. Создать проект: виртуальное окружение, requirements.txt, структура app/{main,schemas,routers}, запуск с --reload.
[40] 4. Описать схемы XCreate, XUpdate, XRead для главной сущности с ограничениями через Field.
[41] 5. Реализовать GET /items (с query-параметрами фильтрации и пагинации) и POST /items (код 201) на хранилище в виде словаря в памяти.
[42] 6. Проверить в Swagger UI: корректный запрос (201), нарушение ограничения (422 — изучить структуру detail), несуществующий id (404).
[43] 7. Добавить GET /health и заполнить метаданные приложения (title, version, description).
[44] 8. Экспортировать openapi.json и приложить его в репозиторий.
[45] Пример
[46] @router.post("", response_model=ItemRead, status_code=201)
[47] def create(payload: ItemCreate, store: Store = Depends(get_store)):
[48]     return store.add(payload)
[49] Самостоятельная часть
[50] Дописать GET /items/{id}, PATCH (с exclude_unset) и DELETE (204); обеспечить 404 во всех трёх случаях отсутствия записи.
[51] Challenge task
[52] Реализовать зависимость Pagination и применить её к двум разным эндпоинтам без дублирования кода; добавить в ответ конверт Page[T] с полями items/total/page/size, типизированный через дженерик.
[53] Результат и критерии
[54] docs/api-design.md + работающий API. Зачтено, если: в путях нет глаголов; для каждого эндпоинта заданы response_model и status_code; схемы разделены на три роли; ошибка 422 воспроизведена и разобрана; Swagger UI отображает все эндпоинты с описаниями.
