# Матрица прав доступа

Проверки из tests/test_auth.py параметризованы: 3 роли × 6 изменяющих операций = 18 комбинаций. Входные данные для разрешённых операций валидны, а удаляемый автор не имеет книг.

| Операция | Гость | member | librarian |
|---|---|---|---|
| POST books | 401 | 403 | 201 |
| PATCH books/{id} | 401 | 403 | 200 |
| DELETE books/{id} | 401 | 403 | 204 |
| POST authors | 401 | 403 | 201 |
| PATCH authors/{id} | 401 | 403 | 200 |
| DELETE authors/{id} | 401 | 403 | 204 |

Каталог читается всеми. Member видит только свои выдачи; librarian видит все. Чужая выдача возвращает 404 как при GET, так и при PATCH. Токен несуществующего пользователя даёт 401. Желаемое хранится на сервере в wishlist_entries и защищено текущей учетной записью: чужие записи недоступны для чтения/удаления. RequireAuth управляет интерфейсом, а сервер проверяет личность независимо от наличия кнопки. Это подтверждают tests/test_integration.py и tests/test_security_regressions.py; текущая production-приемка ролей ожидает пользовательских результатов.
