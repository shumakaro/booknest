# Матрица прав доступа

Проверки из tests/test_auth.py параметризованы: 3 роли × 6 изменяющих операций = 18 комбинаций. Входные данные для разрешённых операций валидны, а удаляемый автор не имеет книг.

| Операция | Гость | member | librarian |
|---|---|---|---|
| POST books | 401 | 403 | 201 |
| PATCH books/{id} | 401 | 403 | 200 |
| DELETE books/{id} | 401 | 403 | 204 |
| POST authors | 401 | 403 | 201 |
| PATCH authors/{id} | 401 | 403 | 200 |
| DELETE authors/{id} | 401 | 403 | 204 |

Каталог читается всеми. Member видит только свои выдачи; librarian видит все. Чужая выдача возвращает 404 как при GET, так и при PATCH. Токен несуществующего пользователя даёт 401. Желаемое остаётся персональным клиентским списком предыдущих лабораторных, защищённым RequireAuth; серверные правила выдач проверяются независимо.
