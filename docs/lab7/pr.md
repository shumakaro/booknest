# Лабораторная работа №7 — Реализация REST API на FastAPI

## Цель работы
В существующий BookNest добавлен REST API книг и авторов с проверяемыми контрактами.

## Выполненные задания
Реализованы CRUD обоих ресурсов, вложенный список книг автора, фильтрация, пагинация, частичное изменение и /health. Добавлены ограничения Pydantic и собственные валидаторы названия, имени и контрольной цифры ISBN.

## Изменения в файлах
Добавлены app/main.py, config.py, schemas, routers, repositories, core, tests. Подготовлены docs/api-design.md, OpenAPI, коллекция HTTP-запросов, Markdown и DOCX отчёта. Типы React генерируются скриптом tools/generate_api_types.py.

## Ход выполнения
Разработка продолжена от lab-6b/router-forms (a481506). Создана отдельная ветка, реализованы маршруты и проверены ошибочные сценарии. Исходные работы сохранены.

## Дополнительные задания
Реализованы сортировка по нескольким полям, единые ошибки с request_id, простой ограничитель изменений и генерация TypeScript-типов с использованием в React.

## Реальные результаты тестирования
16 API-тестов прошли повторно. Ruff: All checks passed. Существующий React-клиент успешно собран. Uvicorn запущен отдельным процессом; /health и /docs вернули 200. Swagger UI открыт в Edge, настоящий скриншот сохранён. Для DOCX создан файл, но визуальная проверка заблокирована отсутствием soffice.exe; отчёт пока требует проверки страниц. Взаимная проверка в паре и внешние учебные drills не проводились.

## Итог работы
Подготовлен API для последующего подключения PostgreSQL. Данные этого этапа хранятся в памяти и сбрасываются при перезапуске.

## Вывод
В ходе работы реализованы маршруты книг и авторов. Проверка данных выполняется средствами Pydantic. Общая пагинация уменьшает повторение кода. Выходные схемы ограничивают состав ответа. Автоматические тесты проверяют успешные операции и основные ошибки. Сохранённый контракт служит основой следующей лабораторной работы.
