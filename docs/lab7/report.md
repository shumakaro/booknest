# Лабораторная работа 7 REST API на FastAPI

## 1 Тема и цель
В существующий BookNest добавлена серверная часть для книг и авторов. Цель работы — освоение ресурсного API, разделения схем и проверки HTTP-контрактов. Данные пока сохраняются в памяти приложения.

## 2 Программное обеспечение
Использованы Python 3.12.14, FastAPI 0.115.12, Pydantic 2.11.4, Uvicorn 0.34.2, pytest 8.3.5, httpx 0.28.1 и Ruff 0.11.8. Точные прямые зависимости зафиксированы в requirements.txt; виртуальное окружение находится в .venv.

## 3 Краткая теория
По лекции 9 FastAPI делает контракт API видимым: аннотации типов становятся проверками и документацией. REST описывает ресурсы существительными, а действие задаётся HTTP-методом. Схемы создания, изменения и чтения выполняют разные роли. Зависимости позволяют повторно использовать пагинацию и подменять хранилище при тестировании.

## 11 Контрольные вопросы лекции 9
### Чем ASGI отличается от WSGI и зачем нужен Uvicorn?
WSGI описывает синхронное взаимодействие сервера и Python-приложения. ASGI поддерживает асинхронные события и долгоживущие соединения. Uvicorn является ASGI-сервером: принимает HTTP-запрос, вызывает приложение FastAPI и отправляет ответ клиенту.
### Как должен выглядеть URL и метод для операций «получить все книги», «создать книгу», «выдать книгу №42»?
GET /api/v1/books читает список, POST /api/v1/books создаёт книгу. Выдача описывается созданием подчинённого ресурса: POST /api/v1/books/42/loans. Глаголы get и create в пути не нужны.
### Когда возвращается 201, 204, 400, 404, 409, 422?
201 означает создание ресурса, 204 — успешное действие без тела ответа. 400 используется для некорректного запроса, 404 — отсутствующего ресурса, 409 — конфликта с текущими данными, например повторного ISBN. 422 означает, что полученное тело или параметры не прошли проверку схемы.
### Зачем разделять схемы Create, Update и Read? Приведите поле, которое есть только в одной из них.
Создание требует обязательных полей, частичное изменение допускает их отсутствие, чтение включает данные, назначенные сервером. id присутствует в Read и отсутствует в Create. Это исключает назначение идентификатора клиентом и позволяет корректно описать PATCH.
### Что делает response_model и какую уязвимость предотвращает?
response_model проверяет и сериализует результат по выходной схеме, отбрасывая лишние поля. Например, UserRead без password_hash предотвращает утечку хеша при возврате ORM-пользователя. Отдельная схема не заменяет проверку прав доступа.
### Как Pydantic сообщает клиенту об ошибке валидации и как выглядит структура ответа?
FastAPI обычно возвращает 422 с массивом detail, где loc показывает путь поля, msg объясняет ошибку, type задаёт её вид. В BookNest централизованный обработчик помещает эти сведения в details единого конверта с code, message и request_id. Проверка выполняется до вызова обработчика маршрута.
### Для чего нужен механизм Depends? Приведите два применения.
Depends получает и передаёт обработчику переиспользуемую зависимость. В работе он выдаёт хранилище приложения и проверенную Pagination. Позже таким же способом создаётся сессия БД и определяется текущий пользователь; тесты могут подменить зависимость.
### Чем PATCH отличается от PUT и что делает exclude_unset=True?
PUT обычно заменяет представление ресурса целиком, PATCH изменяет только часть. exclude_unset=True исключает поля, которых не было в запросе, поэтому значение по умолчанию не затирает сохранённые данные. Явный null остаётся переданным значением и проверяется отдельно.
### Что даёт OpenAPI-схема и как проверить API без клиентского приложения?
OpenAPI описывает методы, пути, параметры, схемы и ответы в машинном формате. Swagger UI строит по ней интерактивную документацию, где можно отправить запрос. Схема также позволяет создавать типизированных клиентов; HTTP-контракты можно проверять httpx/TestClient.
### Почему нельзя выполнять блокирующий код внутри async def?
Блокирующая операция занимает поток цикла событий и задерживает другие запросы. Для асинхронного обработчика нужны неблокирующие библиотеки и await. Синхронные операции допускается выполнять в обычном def, который FastAPI обслуживает в пуле потоков.
