## Владельцы состояния

### App
Хранит основное состояние приложения:
- поисковый запрос;
- фильтры;
- сортировку;
- найденные книги;
- состояние загрузки;
- состояние ошибки;
- текущую страницу;
- общее количество страниц;
- список желаемого;
- состояние темы;
- состояние открытого модального окна.

### SearchPanel
Получает поисковый запрос через props.
Собственного состояния для данных каталога не хранит.

### FiltersPanel
Получает значения фильтров и обработчики через props.
Состояние фильтров находится в App, потому что оно влияет на отображение списка книг.

### BookList
Получает готовый список книг через props.
Самостоятельно не хранит книги в состоянии.

### BookCard
Презентационный компонент.
Показывает информацию о книге и вызывает обработчики добавления или удаления из списка желаемого.

### Badge
Презентационный переиспользуемый компонент.
Используется для отображения небольших информационных меток.

### Button
Универсальный переиспользуемый компонент кнопки.

### Spinner
Презентационный компонент состояния загрузки.

### EmptyState
Презентационный компонент пустого результата.

### ErrorBox
Презентационный компонент ошибки с возможностью повторить действие.

### ThemeToggle
Переключает светлую и тёмную тему.
Выбор пользователя сохраняется в localStorage.

### Modal
Универсальное модальное окно.
Принимает содержимое через children, закрывается клавишей Escape и после закрытия возвращает фокус на элемент, который открыл окно.

### DataTable<T>
Универсальная типизированная таблица.
Поддерживает сортировку по выбранным столбцам без использования any.

## Почему состояние фильтров хранится в App

Фильтры влияют на список книг, поэтому их состояние находится в общем родительском компоненте App. Благодаря этому SearchPanel, FiltersPanel и BookList получают согласованные данные через props, а производные данные можно вычислять во время рендера без дублирования состояния.
