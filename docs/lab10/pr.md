# Лабораторная работа №10 — Full Stack и тестирование

## Цель
React-клиент подключён к собственному API BookNest с реальным сохранением данных и проверкой критического пути.

## Выполненные задания
Каталог, детали, формы, выдача, возврат и персональное желаемое используют FastAPI/PostgreSQL. Фильтры и страницы сохраняются в URL. Прежние поля формы сохранены новыми добавочными миграциями без удаления данных.

## Изменения в файлах
Обновлены API-клиент, адаптеры, страницы, маршруты и ErrorBoundary. Добавлены серверное желаемое, миграции 004/005, интеграционные и клиентские тесты, Playwright, OpenAPI/TypeScript-типы, материалы недели 13 и отчёт.

## Ход выполнения
Проверены реальные контракты и устранена подстановка выдуманных значений при редактировании. Исправлен лишний logout после успешного refresh и последующего 422. Регрессия воспроизведена на отдельной копии кода предыдущей ветки без сброса рабочих файлов.

## Дополнительные задания
Реализованы ErrorBoundary, e2e, оптимистичное желаемое с откатом и анализ покрытия. Выполнен настоящий 30-секундный сценарий истечения access. Точечный override minimatch устранил уведомления npm audit без force-fix.

## Реальные результаты
49 backend-тестов, 4 клиентских и 1 Playwright прошли. Покрытие backend 93%; Ruff, ESLint и production build успешны. В браузере пройдены вход, создание/редактирование, выдача/возврат, регистрация и ограничение member. Истечение: 401 → refresh 200 → повтор 204; исходная настройка восстановлена. npm install после исправления сообщил 0 vulnerabilities. alembic check не нашёл расхождений. Проверка на второй чистой машине и визуальный рендер DOCX ещё не выполнены.

## Итог
Подготовлено локально проверенное Full Stack-приложение. PR направлен в lab-9/jwt-auth, объединение не выполняется.

## Вывод
Источник каталога полностью перенесён на собственный сервер. Пользовательские данные сохраняются в PostgreSQL. Ошибки возвращаются единообразно и понятны интерфейсу. Тесты проверяют доступ, данные, бизнес-правило и восстановление после сбоя. Реальный браузер подтвердил сквозной сценарий и обновление сеанса. Следующим этапом является контейнеризация и проверка в отдельной среде.
