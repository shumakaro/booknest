# Скриншоты для отчетов BookNest

Все шесть DOCX сначала подготовлены отдельно. Этот список предназначен для последующего самостоятельного добавления иллюстраций. Коды в квадратных скобках совпадают с местами внутри соответствующего DOCX.

Снимок вставляется вместо строки ВСТАВИТЬ СКРИНШОТ; подпись Рисунок сохраняется. Если для места нужны несколько кадров, их можно вставить подряд и подписать а/б. На титуле заполняются учебное заведение, ФИО, группа и преподаватель. После вставки проверить переносы страниц в Word.

Пароли, JWT, Authorization, значения cookie, .env и реальные строки подключения не показывать. На рабочем Render/Neon не запускать seed, downgrade, restore, down -v или prune. Изменяющие сценарии делать только на отдельном тестовом стенде либо со своей новой тестовой записью и завершением возврата.

## Что нельзя заменить скриншотом

Взаимное ревью требует настоящего проекта однокурсника, минимум8 комментариев (два о безопасности), ответного ревью и ответов коммитами. Преподавательские sql-drills/vuln-lab/сломанный Docker-стенд/патч не предоставлены. Эти действия не выполнены и описаны как незавершенные. Фото собственного проекта не закрывает их.

Uptime: сначала нужен реально подключенный внешний мониторинг и накопленная история. Автоматический ежедневный backup: сначала нужно подтвердить работающий планировщик. VPS SSH/firewall/certbot: требуется отдельный VPS-стенд или согласованная замена в облачном варианте. Публичный Lighthouse следует действительно запустить; прежние локальные оценки не переносить.

Временная ветка Neon br-weathered-rice-beyaagz5 истекает11 ноября2026 в18:00UTC (23:00Asia/Qyzylorda). Сохраненные JSON являются доказательством прежнего теста, не гарантируют наличие ветки позже. Новый restore допускается только в новую пустую тестовую БД, не в production.

Скриншоты из прежних docs/lab7–lab12 можно использовать, если они соответствуют описанному историческому этапу. Для нового оформления и публичных функций нужны актуальные кадры. Наличие картинки не означает, что команда запускалась заново.
