# Микропроект недели 12 Мини API задач

Самостоятельный сервис другой предметной области, размещённый в существующем репозитории, использует пять эндпоинтов: POST /token, GET /tasks, POST /tasks, GET /tasks/{id}, PATCH /tasks/{id}. Все операции задач требуют Bearer JWT. Хранилище в памяти сбрасывается при перезапуске, данные BookNest не используются.

Для отдельного запуска в окружении задаются MINI_SECRET_KEY (случайный ключ от 32 символов), MINI_USERNAME и MINI_PASSWORD_HASH (bcrypt). Пароль в открытом виде в файл не сохраняется. Запуск: `python -m uvicorn examples.mini_api.main:create_app --factory --port <свободный порт>`. Проверка: `python -m pytest tests/test_mini_api.py -q`.

Выбор темы является учебным вариантом переноса навыка; списка тем преподавателя нет, его утверждение не выдумывается.
